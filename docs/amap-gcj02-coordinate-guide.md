# 高德坐标获取方法

本文用于后台管理员配置「飞豹救援地理位置」时，正确获取高德 GCJ02 坐标。

## 一、坐标要求

- 后台表单中的 `经度（lng）`、`纬度（lat）` 必须填写高德 `GCJ02` 坐标。
- 前端地图会直接使用后台保存的坐标渲染，不再做地址转坐标兜底。
- 地址、点位名称、电话、经纬度建议同时维护，保证前后台展示一致。

## 二、推荐获取方式

### 方法 1：高德开放平台坐标拾取器

1. 打开高德开放平台坐标拾取器。
2. 搜索目标地址，或直接在地图上点击目标建筑/院落/营区入口。
3. 读取页面显示的经纬度。
4. 将经度填入后台 `lng`，纬度填入后台 `lat`。

适用场景：

- 已知精确门牌号
- 需要把点位落在园区入口、院门、办公楼等更细位置

### 方法 2：高德地图网页端

1. 打开高德地图网页版。
2. 搜索详细地址。
3. 将地图放大到建筑级别。
4. 右键或点击目标位置，查看坐标信息。
5. 将经纬度回填到后台。

适用场景：

- 地址文案已经比较准确
- 需要人工微调点位

## 三、后台填写建议

- `点位名称`：填写地图上希望展示的名称，例如“特勤大队驻地”。
- `详细地址`：尽量填写到街道、门牌号、园区或高速出入口，不要只写区县。
- `经度（lng）`：例如 `103.828950`
- `纬度（lat）`：例如 `30.706120`

## 四、校验方法

1. 后台进入「地理位置」编辑对应队伍。
2. 更新地址、点位名称、电话、经纬度后保存。
3. 刷新前台「地理位置」页面。
4. 检查顶部 Tab、地图标记点、地图弹窗、底部地址电话是否为同一条后台记录。

## 五、注意事项

- 不要填写百度坐标或 WGS84 坐标，避免前端高德地图出现偏移。
- 如果地图点位正确但地址文案不精确，应优先修正后台详细地址。
- 如果地址正确但标记点偏移，应重新在高德地图上拾取更精确的 GCJ02 坐标。
