# 后台管理系统表格列宽优化方案

## 标准列宽规范

### 1. 固定宽度列
- **序号列**: 60px
- **状态列**: 80px
- **排序列**: 80px
- **数量/次数列**: 90px
- **姓名列**: 100px
- **部门/分类列**: 100px
- **职位列**: 100px
- **日期列**: 110px (YYYY-MM-DD格式)
- **时间列**: 160px (YYYY-MM-DD HH:mm格式)
- **完整时间列**: 180px (YYYY-MM-DD HH:mm:ss格式)
- **编号列**: 120px (证书编号、人员编号等)
- **电话列**: 120px
- **图片列**: 120px
- **身份证号列**: 180px
- **操作列**: 150px (固定右侧)

### 2. 弹性宽度列
- **标题列**: min-width="200"
- **内容/描述列**: min-width="200"
- **地址列**: min-width="180"
- **单位名称列**: min-width="140"

## 优化原则

1. **一致性**: 相同类型的列使用相同宽度
2. **适配性**: 使用min-width让长内容自动扩展
3. **可读性**: 确保内容不会过度拥挤
4. **响应式**: 重要列使用弹性宽度

## 需要调整的页面

### 高优先级
- Banner.vue - 创建时间列 180px → 160px
- News.vue - 统一日期格式和宽度
- Certificates.vue - 优化多列布局
- Personnel.vue - 优化多列布局

### 中优先级
- Vehicles.vue
- RescueCases.vue
- Policy.vue
- Leadership.vue

### 低优先级
- 其他管理页面

## 实施步骤

1. 创建全局样式变量（可选）
2. 逐页面应用标准列宽
3. 测试不同分辨率下的显示效果
4. 根据实际使用反馈微调
