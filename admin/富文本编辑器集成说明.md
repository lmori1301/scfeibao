# 富文本编辑器集成说明

## 安装依赖

在 admin 目录下执行：

```bash
npm install @wangeditor/editor @wangeditor/editor-for-vue
```

## 已更新的页面

1. **News.vue** - 新闻管理
2. **Party.vue** - 党建专栏（待更新）
3. **TeamIntro.vue** - 队伍介绍（待更新）
4. **RescueCases.vue** - 救援案例（待更新）

## 使用方法

在需要富文本编辑器的页面中：

```vue
<script setup lang="ts">
import RichTextEditor from '@/components/RichTextEditor.vue'
</script>

<template>
  <RichTextEditor v-model="formData.content" placeholder="请输入内容" height="300px" />
</template>
```

## 组件参数

- `v-model`: 绑定的内容（HTML格式）
- `placeholder`: 占位符文本（可选）
- `height`: 编辑器高度（可选，默认400px）
